# 上线部署记录（2026-10-18）

> 本文只记录部署形态与运维流程；**真实密钥、完整服务器 IP 不要写进任何进 git 的文件**。
> 服务器 IP / 控制台入口见你的阿里云控制台；密钥见服务器 `/opt/blog/.env`。

## 1. 线上形态

| 项 | 值 |
|---|---|
| 访问地址 | **https://hailin.kdns.fr** |
| 链路 | 浏览器 → Cloudflare（免费 HTTPS，Full strict）→ 源站 HTTPS:443 → Nginx → 后端 |
| 服务器 | 阿里云 ECS 香港节点（2C8G / Ubuntu 22.04 / 40G ESSD，免费试用 465 小时） |
| 部署方式 | Docker Compose 五容器：mysql / redis / es(+IK) / backend / nginx |
| 代码目录 | `/opt/blog`（数据卷：mysql-data / redis-data / es-data；日志：logs/） |
| 证书 | Cloudflare **Origin Certificate**（15 年），`/opt/blog/nginx/certs/{origin.pem,origin.key}`；CF 模式 **Full (strict)** |
| 数据库 | 全新库（`db/init.sql` 初始化：29 表 + 6 分类：后端/前端/AI Agent/开发工具/代码人生/阅读） |
| 旧服务器 | 47.88.86.213（美国节点），保留作回滚，稳定后释放 |

## 2. 关键决策记录

- **不迁移旧数据**：新站全新开始（分类改版后旧文章语义映射不再需要）。
- **默认分类 = 阅读**（没选分类的文章归"阅读"）。
- **游客 AI 保留免费**，但四道闸门：每 IP 10 次/天、全站游客 2000 次/天、全站 AI 120 次/分钟、per-IP/user 窗口限流。
- **ES 堆 1G**、后端堆 1.5G、MySQL buffer 512M、Redis 256M（8G 档；当前内存占用约 4.7G，余量充足）。
- **HTTPS**：CF 从 Flexible 改 Full + Origin 证书（全链路加密）。

## 3. 上线后更新代码（不用重新部署）


## 4. 运行中改配置

| 改什么 | 怎么改 | 生效 |
|---|---|---|
| 模型、开关、限流额度、邮箱、OAuth | `/opt/blog/.env` | `docker compose restart backend` |
| application.yml 里的项（RAG 门限、白名单等） | `/opt/blog/backend/config/application.yml` | `docker compose restart backend` |
| Nginx 行为（缓存头、限流等） | `/opt/blog/nginx/blog.conf` | `docker compose up -d nginx` |

换模型注意：换 embedding 必须重建 RAG 索引（重建接口需临时开白名单）；换 rerank 模型必须重标定 gate 阈值。

## 5. 备份

`/etc/cron.daily/blog-backup`（每日 03:00 左右由 cron 触发）：mysqldump → `/opt/blog/backup/blog_<日期>.sql.gz`，保留 14 天。
恢复演练：`gunzip -c backup.sql.gz | docker exec -i blog-mysql mysql -uroot -p<密码> blog_system`。

## 6. 回滚

- **整站回滚旧服务器**：Cloudflare DNS → A 记录改回旧 IP（旧服务器需保持运行）。
- **代码回滚**：本地 git `git revert`/checkout 对应 commit → 重新构建上传（或用服务器上 `backend/app.jar.bak`）。
- **Nginx 回滚**：`cp nginx/blog.conf.bak nginx/blog.conf && docker compose up -d nginx`。
- **证书/模式回滚**：CF SSL/TLS 模式临时改回 **Flexible**（源站 80 仍在监听）。

## 8. 常用运维命令

```bash
cd /opt/blog
docker compose ps                          # 服务状态
docker compose logs -f backend             # 后端日志（[SENSITIVE]/[JEV]/[SEARCH-INDEX]/[THINKING]）
docker compose restart backend             # 改了 .env 或外部配置
docker compose up -d nginx                 # 改了 nginx 配置
docker stats                               # 资源占用
curl -s http://127.0.0.1:8080/actuator/health
docker exec blog-es curl -s "http://localhost:9200/_alias/article_rag_active"   # RAG 别名
docker exec blog-mysql mysql -uroot -p$(grep '^MYSQL_ROOT_PASSWORD=' .env | cut -d= -f2) -e "show tables"
```
